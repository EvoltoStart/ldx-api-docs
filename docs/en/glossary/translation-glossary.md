# Translation Glossary

This glossary defines standard English terms used in the LDX API documentation.

## Core Terms

| Chinese | English | Notes |
| --- | --- | --- |
| 渠道 | Channel | Upstream provider configuration. |
| 令牌 | Token | User API token or access credential. |
| 兑换码 | Redemption Code | Code used to redeem quota or benefits. |
| 订阅 | Subscription | User subscription or package entitlement. |
| 订单 | Order | Payment or billing order. |
| 模型中转 | Model Relay | OpenAI-compatible model forwarding layer. |

## Translation Rule

Use consistent terms across UI, API documentation, and release notes. Prefer concise technical English over literal translation.
