# LDX API 文档

这里是 LDX API 的开发者文档入口，用于集中维护后端接口说明、OpenAPI Reference 和 Mintlify 部署流程。

当前文档采用如下发布方式：

```text
内网 GitLab 源仓库
        ↓ GitLab CI 白名单同步
GitHub docs-only 发布仓库
        ↓ Mintlify 自动部署
Mintlify 文档站点
```

## 当前内容

- `docs/openapi/api.json`：业务接口 OpenAPI 描述。
- `docs/openapi/relay.json`：模型中转接口 OpenAPI 描述。
- `docs/mintlify-deployment.md`：Mintlify 文档部署流程。

## 维护原则

- 内网 GitLab 是文档源头。
- GitHub 仓库只保存允许发布到 Mintlify 的文档子集。
- 同步内容必须走白名单，避免误上传内部测试报告、SQL 文件、日志或敏感说明。
