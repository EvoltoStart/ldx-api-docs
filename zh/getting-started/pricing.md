实际费用会随模型、输入长度、输出长度、分辨率、视频秒数、音频秒数、缓存命中情况和调用参数变化。表格中的 `/` 表示未提供单独价格、该项不适用，或该模型在对应供应商下未整理到价格。

## 计费口径

| 类型 | 常见计费单位 | 说明 |
| --- | --- | --- |
| 大语言模型 | 元 / 百万 tokens | 通常区分输入和输出；部分模型按上下文长度分档。 |
| 视频生成模型 | 元 / 秒、元 / 百万 tokens | 火山 Seedance 系列同时提供 tokens 价格；其他视频模型主要按秒计费。 |
| 图像生成模型 | 元 / 张 | 部分模型会按是否关闭提示词改写区分价格。 |
| 全模态大模型 | 元 / 百万 tokens | 文本、图片、视频、音频输入以及文本、音频输出可能分别计价。 |
| 语音合成模型 | 元 / 万字符 | txt 中输出单价为不计费。 |
| 语音识别模型 | 元 / 秒 | txt 中输出单价为不计费。 |
| 其他模型 | 元 / 百万 tokens | 包括界面交互、角色扮演等模型。 |

免费额度、折扣和限时优惠来自上游厂商规则，通常有有效期或触发条件；估算成本时不要把免费额度视为长期固定价格。

## 价格使用建议

1. 文本模型先确认上下文长度分档，再估算输入 tokens、输出 tokens 和缓存相关费用。
2. 视频模型先确认分辨率、秒数、有声/无声、是否含视频输入，以及请求是生成、参考生视频还是视频编辑。
3. 图像模型先确认输出张数，以及 `z-image-turbo` 是否关闭提示词改写。
4. 全模态模型先区分输入模态和输出模态；音频输入、文本输出、文本+音频输出可能使用不同单价。
5. 语音模型先确认单位：TTS 按字符计费，ASR 按秒计费。
6. 免费额度和折扣只用于试用和成本预估，实际可用额度以开通时间、有效期和上游规则为准。
